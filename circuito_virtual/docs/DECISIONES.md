# Decisiones de circuito_virtual

Numeración propia con prefijo **V**. La historia anterior (hallazgos H, excepciones X, decisiones D
y preguntas P de A1-A2 y de la rampa del BC)
sigue en `experimental/docs/DECISIONES.md`; aquí solo se anota lo que se decide a partir del
2026-11-01. Las filas citan allí lo que las originó.

Cada **Vnn es una entrada de este registro, no una versión del software**: la versión del software es
el commit de git que cada sesión guarda en la cabecera de su log. Las cifras de entradas anteriores son
referencia; cada sesión nueva se juzga contra el criterio de volante de V19 y contra su propio log.
